# Contributing

## Prerequisites

- Node.js 22+
- pnpm 10+

## Local Setup

1. Copy `.env.example` to `.env.local` and fill in placeholders as needed.
2. Run `pnpm install`.
3. Start the workspace with `pnpm dev`.

## Common Commands

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`

## Phase Rule

This repository follows the approved phase plan in [docs/phase-0/release-plan.md](./docs/phase-0/release-plan.md). Do not start a later phase before the current phase DoD is met.
